# PRD (요약) — 에너지인력양성센터 AI 안내 데스크

작성일 2026-10-07 · 상세는 `../서비스_기획서.md`

## 문제
학생이 센터 문의를 어디에, 무엇을 준비해서 보내야 하는지 몰라 두 번 걸음한다. 센터는 같은 절차 안내를 반복한다.

## 목표
- 한 페이지에서 센터·프로그램 소개를 보고, 문의 전에 AI가 담당 부서·절차·서류를 1차 안내한다.
- 확정이 필요한 것은 "확인 필요"로 표시하고 구글 폼(B3 자동화)으로 넘긴다.

## 범위 (MVP, 10-10 마감)
| 포함 | 제외 |
|---|---|
| 단일 페이지 섹션 5개 + 고정 메뉴 + 햄버거 | 로그인, 다국어, DB 저장 |
| AI 문의 도우미 1개(유형+내용 → 카드 5칸) | 자유 대화(멀티턴) 챗봇 |
| 실패 처리 3종(빈 입력·API 오류·20초 타임아웃) | 스트리밍 응답 |
| Vercel Python 함수 1개 `api/ask.py` | 관리자 화면 |
| 반응형 900/600px | 접근성 전수 점검(기본 label·포커스만) |

## 성공 기준
1. 배포 URL에서 메뉴 5개 이동, 데스크톱·모바일 레이아웃 정상.
2. 테스트 입력 3건 모두 JSON 5필드가 카드로 표시된다.
3. 빈 입력·오류·타임아웃 각각 안내 문구가 보인다.
4. 저장소·캡처·README 어디에도 키가 없다.

## 핵심 결정
- 담당 부서는 B3와 같은 3개(프로그램 운영 / 학생인건비 / 센터 총괄)로 고정해 AI가 지어내지 못하게 한다.
- `response_format` 미지원 프록시이므로 JSON은 프롬프트로 강제 + 서버 파싱 보정 + 1회 재요청.
- `max_tokens` 생략(gemini-3-flash 사고 토큰 포함 문제).
- Vercel 함수는 `BaseHTTPRequestHandler` 방식, 외부 패키지는 `requests`만.

## 리스크
| 리스크 | 대응 |
|---|---|
| 프록시 간헐 400 | 프롬프트 길이 최소화, 400이면 짧은 프롬프트로 1회 재시도 |
| Vercel 콜드 스타트 + LLM 지연 > 20초 | 프론트 타임아웃 안내, 서버 타임아웃 18초로 먼저 끊어 502 반환 |
| 모델이 실명·금액 단정 | 시스템 프롬프트 금지 조항 + notes 강제 |
